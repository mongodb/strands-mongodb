# strands-mongodb

MongoDB backends for the [Strands Agents SDK](https://github.com/strands-agents/harness-sdk):
a `Storage` implementation for agent state and a `MemoryStore` implementation backed by
Atlas Search and Atlas Vector Search.

Repository bootstrap. The Python package, its test suite and its documentation arrive through
the pull requests tracked in PENGINT-151; this file is replaced by the package README in the
first of them.
